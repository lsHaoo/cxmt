# 2. 执行: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
# 3. 执行: .\download-windows.ps1

# 脚本会自动下载以下文件：
# - Claude Code 安装脚本
# - Node.js 安装包 (MSI 和 ZIP 格式)
# - ripgrep 工具
# - Homebrew 安装脚本（保留但 Windows 不使用）

# 需要手动下载的文件：
# - Git for Windows (因为官方安装包可能没有直接的下载链接)

# 注意事项
# ========================================

# 1. 某些文件（如 Git for Windows）需要手动从官网下载
#    因为官方安装包可能没有直接的下载链接
