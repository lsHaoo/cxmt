========================================
使用说明
========================================

准备阶段（联网机器）：
1. 运行 download-windows.ps1 自动下载大部分文件
2. 手动下载 Git for Windows（必需）
3. 可选：手动下载 Claude Code 二进制文件
4. 打包整个文件夹传输到离线环境

安装阶段（离线机器）：
1. 解压安装包
2. 以管理员身份运行 install-offline.ps1
3. 重启终端
4. 配置 API 密钥
5. 验证安装

详细操作步骤请参考 README.md
快速开始请参考 QUICKSTART.md
