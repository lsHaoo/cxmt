## 1. 产品概述

### 1.1 产品定位
面向企业内部的 AI 服务成本管理平台，帮助企业管理多个 AI 服务商（OpenAI、Azure、智谱、通义千问等）的成本消耗，实现成本透明化、预算可控、数据可分析。

### 1.2 产品价值
- **成本透明**：准确统计每个用户的 AI 服务使用成本
- **实时监控**：实时查看成本消耗情况，及时发现异常
- **预算可控**：支持预算设置和预警，避免超支
- **数据驱动**：提供多维度数据分析，支持决策优化

### 1.3 适用场景
- 企业内部有多个部门使用 AI 服务
- 需要按用户/项目统计成本消耗
- 需要设置预算并进行预警
- 需要分析成本构成和使用趋势

## 3. 交互说明

### 3.1 导航栏
- 点击菜单项切换页面
- 用户头像下拉显示：个人中心、退出登录

### 3.2 成本明细筛选
- 日期选择：支持日历选择或快捷选择（今天、本周、本月）
- 服务商/模型：多选下拉框
- 查询后列表自动刷新

### 3.3 预算设置
- 修改预算需二次确认
- 保存后立即生效
- 预算周期切换自动计算周期范围

### 3.4 API Key 操作
- 复制 API Key 到剪贴板
- 重置 Key 后旧 Key 立即失效
- 禁用后该用户无法调用 API

### 3.5 导出功能
- 导出 Excel 文件
- 支持当前筛选条件下的所有数据
- 大数据量导出异步处理
