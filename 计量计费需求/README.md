# 计量计费需求目录

## 目录说明

本目录存放 AI 成本管理平台的需求文档和原型设计。

## 文件列表

### 1. AI成本管理平台-产品需求文档.md
完整的产品需求文档，包含：
- 产品概述
- 用户画像
- 详细功能需求（7大模块）
- 非功能需求
- 页面原型（ASCII 格式）
- 数据需求
- 用户故事

### 2. prototype.html
交互式原型页面，可在浏览器中直接打开查看效果。

**使用方法：**
1. 用浏览器打开 `prototype.html`
2. 点击"登录"按钮进入系统
3. 通过导航栏切换不同页面
4. 点击按钮查看弹窗效果

## 目录结构

```
计量计费需求/
├── README.md              # 说明文档
├── AI成本管理平台-产品需求文档.md  # 产品需求文档
└── prototype.html          # 交互原型
```

## 相关背景

这是面向企业内部的 AI 服务成本管理平台，帮助企业统一管理多个 AI 服务商的成本消耗，实现成本透明化、预算可控、数据可分析。

**目标用户：** 10000+ 用户
**技术栈：** Vue3 + Vite + Antd (前端) / Spring Boot + MySQL (后端)
