# Frontend Design

A comprehensive frontend design assistant for creating modern, responsive, and accessible user interfaces.

## Features

### UI Component Design
- Create reusable UI components (buttons, cards, modals, etc.)
- Follow modern design patterns and best practices
- Ensure accessibility (ARIA, keyboard navigation)
- Optimize for mobile and desktop

### Layout Systems
- Flexbox and Grid layouts
- Responsive design patterns
- Mobile-first approach
- Cross-browser compatibility

### Styling
- Modern CSS (custom properties, container queries, etc.)
- CSS-in-JS solutions
- Utility-first CSS frameworks
- Design systems and tokens

## Usage

Request UI designs by describing:
- Component type and purpose
- Visual style requirements
- Responsive behavior needed
- Accessibility requirements

Examples:
- "Create a responsive card component with hover effects"
- "Design a mobile-friendly navigation menu"
- "Build a modal dialog with animations"

## Frameworks Supported

- React / Next.js
- Vue / Nuxt
- Svelte / SvelteKit
- Vanilla JavaScript
- Modern CSS (Tailwind, CSS Modules, etc.)
